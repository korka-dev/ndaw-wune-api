# Lot L10 — Base 2026-2027, écoles FLS, nom « NdawWune »

## Ce qui change

- **Import / Export (admin)** : l'import lit directement la base 2026-2027
  (premier onglet « Base_application », colonnes du format import-export + colonne `FLS`).
  - Comptes tuteurs / superviseurs retrouvés d'abord **par téléphone** ; un compte
    retrouvé dans une autre école y est réaffecté. Un numéro déjà pris par un autre
    rôle refuse la ligne (message explicite).
  - Écoles et élèves existants **mis à jour** (IEF, commune, directeur, langue, FLS ;
    classe, type titulaire / remplaçant, sexe). Une cellule vide ne remplace rien.
  - Homonymes (même nom, même classe, autre code) : deux élèves distincts, le code
    élève est ajouté au prénom (35 cas dans la base du 26/11/2026).
  - Option **« Nouvelle année scolaire »** : classes des tuteurs = celles du fichier ;
    élèves, tuteurs et superviseurs absents du fichier **archivés** (réversible,
    historique conservé, comptes déconnectés).
  - Avertissement pour les classes sans tuteur (SOBEME SESSENE, NWN 1, dans la base).
  - L'export ajoute la colonne `FLS` (Oui / Non).
- **Gestion École** : bouton « Répartition FLS » → import du fichier
  `Extraction_IA_IEF_ecoles_FLS.xlsx` (même écran que dans Gestion Planning).
- **App mobile** : profil → « Français langue seconde : École avec / sans FLS ».
  Nom de l'application : « NdawWune » (changement natif : nouvel APK).
- API : `APP_NAME` par défaut « NdawWune ».

Aucune migration de base de données.

## Mise en production

1. Sauvegarde de la base (obligatoire avant un import « nouvelle année »).
2. Déployer l'API puis l'admin sur la branche `lot-L10-base-2026`
   (`API_DOMAIN=api.ndawwune.ared-edu.org bash scripts/redeploy.sh`, puis
   `bash deploy_docker.sh` côté admin), et `scripts/verifier_deploiement.sh`.
3. Admin → Import / Export → cocher « Nouvelle année scolaire » → choisir le fichier.
   L'aperçu n'enregistre rien : vérifier les compteurs (5 000 élèves, 99 tuteurs,
   79 superviseurs, 100 classes attendus), les élèves / comptes qui seront archivés,
   les lignes refusées et la rubrique « À vérifier ». Puis confirmer.
4. Gestion École → « Répartition FLS » → importer `Extraction_IA_IEF_ecoles_FLS.xlsx`
   si des écoles restent « FLS non renseigné » (la base les renseigne déjà via sa
   colonne FLS).
5. Mobile : `npx eas-cli build --profile preview --platform android` (nouveau nom ;
   inclut aussi la 1.4.0 de L8), puis `LATEST_APP_VERSION` dans le `.env` de prod
   après distribution.

Avant l'import, le classeur recommande de revoir l'onglet `A_verifier` (39 points :
16 élèves signalés, 9 directeurs divergents, 6 effectifs de remplaçants, etc.) et
de prévenir les tuteurs. Les comptes créés avec le numéro du fichier reçoivent le
mot de passe temporaire habituel (`DEFAULT_USER_PASSWORD`, changement obligatoire à
la première connexion), comme un compte créé depuis le dashboard. Les comptes
existants retrouvés par téléphone gardent leur mot de passe.
